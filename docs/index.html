A desktop utility for testing compatible Modbus RTU devices over serial connections. Inspect register values and test supported read/write operations from one interface.

↓ Download for Windows View GitHub Repository ↗

Designed for Windows computers with a compatible serial adapter and Modbus RTU device.

Features

Tools for your Modbus workflow

🔌 Serial Connection

Configure the COM port and communication settings to match your device.

▦ Register Reading

Inspect supported coils, discrete inputs, holding registers and input registers.

✎ Write Testing

Test supported write operations using verified addresses and a safe test device.

⟳ Live Polling

Refresh data periodically when polling is supported and enabled.

⌁ Communication Logs

Use available logs to help investigate connection and communication issues.

🖥 Windows Desktop

Communicate with serial hardware on the computer running the application.

Getting started

Three steps to get started

1. Download

Download the release files and extract all parts into the same folder if the release is split.

2. Connect

Connect your serial/RS485 adapter and choose the correct COM port and device settings.

3. Test

Start with a known, safe register read. Verify addresses before writing any values.

This website is for product information and downloads. It does not connect to a visitor's local COM port. Only run software you trust and have verified.
